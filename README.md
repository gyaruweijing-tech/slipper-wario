# スリッパを捨てるな

メイドインワリオ風の短時間ミニゲーム集。**`index.html` 1枚だけ**で動きます。

あなたは、よかれと思ってよその一足を捨ててしまった。その日から、守る側になった。
迫りくる「片づけたい気持ち」を約4秒でしりぞけよ。

## あそびかた

ミニゲーム11種 × 難易度3段階。4ラウンドごとに速くなる。
ライフ3つ。使い切ると称号が出ます（一般人 → 見習い → 中堅信徒 → 守護長老 → 玄関大明神）。

お題の前に**「かまえ」**が出ます。これは Wii版メイドインワリオの「フォーム」にあたるもので、
どう操作するかの宣言です。**前のラウンドと操作が変わるときだけ出る**ので、
かまえカードが出たら持ちかたを変える合図。

| かまえ | 操作 |
|---|---|
| たたく | ねらってタップ |
| れんだ | すばやく何度もタップ |
| こする | 指をすべらせて払う（向き指定あり） |
| おさえる | 指を離さず押さえつづける（指2本の場面あり） |
| はこぶ | つまんだままドラッグして離す |

| お題 | かまえ | やること |
|---|---|---|
| まもれ！ | たたく | 迫るゴミ袋をタップして壊す |
| ひろえ！ | たたく | 落ちるスリッパを全部キャッチ |
| さがせ！ | たたく | 履物の山からスリッパを見つける |
| そろえろ！ | たたく | 見本と同じスリッパを選ぶ |
| となえろ！ | たたく | 「ス→リ→ッ→パ→を」の順に唱える |
| えらべ！ | たたく | 教義にしたがう（「かたづける」も罪） |
| とめろ！ | れんだ | 連打でスリッパを引き戻す |
| はらえ！ | こする | 積もった埃をこすって落とす |
| ひっぱれ！ | こする | 矢印の向きにこすって引き寄せる |
| おさえろ！ | おさえる | ゴミ箱のフタを押さえつづける |
| しまえ！ | はこぶ | 下駄箱の枠まで運んで離す |

## 動かす

`index.html` をブラウザで開くだけ。ローカルサーバーで見るなら:

```bash
npx -y http-server . -p 5178 -c-1
```

## スマホに入れる（PWA）

HTTPSで配信されていれば、ホーム画面に追加するとアプリとして起動します（全画面・オフライン可）。

- iPhone: Safariで開く → 共有 → **ホーム画面に追加**
- Android: Chromeで開く → メニュー → **アプリをインストール**

アイコンは `icons/` に生成済み。作り直すときは:

```bash
node tools/gen-icons.js icons
```

外部ライブラリなし（Nodeの `zlib` だけ）でPNGを書き出します。玄関にそろえて置かれたスリッパ2足のデザインです。

## 技術メモ

- 依存ゼロ・ビルド不要の単一HTML（HTML + CSS + 素のJS）
- 効果音とBGMは **WebAudio でその場で合成**（音声ファイル0個）
- **絵はすべてインラインSVG。絵文字は1つも使っていない**
  （絵文字はOSごとに別の絵になるため、端末によって見た目もアタリの見えかたも変わってしまう）
- ハイスコアは localStorage 保存

### 絵のルール（スタイル憲法）

新しい絵を足すときは必ずこれに従うこと。ここが崩れると全体が安っぽくなる。

1. 線は `#2B2A26` 一色、太さ **3** 固定（`viewBox` 幅60基準）
2. グラデーション・ドロップシャドウ **禁止**
3. 1つにつき塗りは2色まで（本体色＋べた影）
4. パレット固定：生成り `#FBF7EF` / 墨 `#2B2A26` / 畳 `#3F7D5E` / 金 `#C9A227` / 朱 `#D9534F`
5. 顔は **点目と線の口だけ**。白目・ハイライトは描かない
6. 影は落ち影を使わず、面の下側を同系の暗色でベタ塗り（`shade()` ヘルパ）

真上から見たスリッパは小さくすると目玉に見えるので、
小さく出す場所では横から見た `slipperSide()`、大きく見せる場所では2足並べた `slipperPair()` を使う。

開発の経緯と仕様の詳細は [PROGRESS.md](PROGRESS.md) を参照。
