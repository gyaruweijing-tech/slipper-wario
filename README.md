# スリッパを捨てるな 🩴

メイドインワリオ風の短時間ミニゲーム集。**`index.html` 1枚だけ**で動きます。

あなたは玄関を守る守護者。迫りくる廃棄の意志（ゴミ袋・ゴミ箱・母）を約4秒でしりぞけよ。

## あそびかた

- 操作は**タップ / クリックのみ**（スマホ・PC 両対応）
- ミニゲーム7種 × 難易度3段階。4ラウンドごとに速くなる
- ライフ🩴3つ。使い切ると称号が出ます（一般人 → 見習い → 中堅信徒 → 守護長老 → 玄関大明神）

| お題 | やること |
|---|---|
| まもれ！ | 迫るゴミ袋をタップして壊す |
| ひろえ！ | 落ちるスリッパを全部キャッチ |
| さがせ！ | 履物の山からスリッパを見つける |
| そろえろ！ | 見本と同じスリッパを選ぶ |
| とめろ！ | 連打でスリッパを引き戻す |
| となえろ！ | 「ス→リ→ッ→パ→を」の順に唱える |
| えらべ！ | 教義にしたがう（＝捨てない） |

## 動かす

`index.html` をブラウザで開くだけ。ローカルサーバーで見るなら:

```bash
npx -y http-server . -p 5178 -c-1
```

## 技術メモ

- 依存ゼロ・ビルド不要の単一HTML（HTML + CSS + 素のJS）
- 効果音とBGMは **WebAudio でその場で合成**（音声ファイル0個）
- スリッパはインラインSVG（日本のスリッパの絵文字が存在しないため）
- ハイスコアは localStorage 保存

開発の経緯と仕様の詳細は [PROGRESS.md](PROGRESS.md) を参照。
