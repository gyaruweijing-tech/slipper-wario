# assets/

`index.html` は起動時にここを見にいきます。**ファイルが無くても壊れません**
（読めなければ黙って組み込みのSVGを使います）。置けば次の再読み込みで差し替わります。

| ファイル | 用途 | 仕様 |
|---|---|---|
| `char-guardian.png` | 主人公・守護者 | **背景透過**PNG。全身・正面。長辺600px程度 |
| `char-tidier.png` | かたづけ魔 | 同上 |
| `logo.png` | タイトルロゴ | **背景透過**PNG。横長。「スリッパを捨てるな」 |
| `opening.mp4` | オープニング動画 | H.264 / yuv420p / **音声なし** / 1280×720（横長）/ 8秒 / 1.5MB以下 |

動画は**横長のまま**、墨色の余白と金の細線で縁取って映画のように再生します。
縦にトリミングしません。再生中はHUDも消えます。

## 背景は必ず透過にすること

画面の背景がクリーム色（`#FBF7EF`）なので、白背景のPNGを置くと
キャラの周りに**白い四角が出ます**。書き出しのときに背景を透明にしてください。

## キャラ画像の絵柄

`README.md` の「絵のルール（スタイル憲法）」に合わせること。とくに:

- 線は墨色 `#2B2A26` の**太さの一定した輪郭線**
- 塗りは**ベタ塗りのみ**。グラデーション・光沢・影のぼかしは使わない
- 色は 生成り `#FBF7EF` / 墨 `#2B2A26` / 畳 `#3F7D5E` / 金 `#C9A227` / 朱 `#D9534F` の5色だけ
- 顔は**点目と線の口だけ**。白目・ハイライト・**頬の赤み**・眉・鼻は描かない

## 動画の作りかた

Gemini などの出力をそのまま `opening-raw.mp4` として置いてコミットすれば、
こちらで圧縮・変換します。自分で変換する場合は:

```bash
ffmpeg -i opening-raw.mp4 -an \
  -vf "scale=1280:720:force_original_aspect_ratio=decrease,fps=30" \
  -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 26 -preset slow \
  -movflags +faststart opening.mp4
```

Git LFS は不要です。数MBのファイルは普通に `git add` できます。
